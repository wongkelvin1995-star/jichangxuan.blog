用 ChatGPT、Claude、Gemini 时该连哪个节点？流传很广的说法是“AI 工具先选香港或台湾”。这条经验靠不住：服务判断你在哪里，看的是出口 IP 被它判定的地区，不看节点叫什么；而 OpenAI 开发者文档与 Anthropic 公布的支持名单里，都没有香港。

本文分三步：先看三家官方名单（2026-11-16 查阅），再看本站灵动云记录里出口被判成了哪里，最后讲怎么自查、怎么固定节点。流媒体的地区判定与带宽，另见[看 YouTube 4K 与 Netflix 需要多少网速和流量](/guides/youtube-4k-netflix-network-guide/)。

## 服务看的是出口 IP，不是节点名

节点名是机场自己起的。你的流量从入口进入机场线路，再从境外的某个出口离开，ChatGPT 这类服务只看得到出口 IP。专线机场的入口在境内、出口在境外，两者的关系见[IEPL 与 IPLC 有什么区别](/speedtest/iepl-vs-iplc/)。

服务靠 IP 地址库把出口 IP 对应到地区。地址库不止一家，同一个 IP 在不同库里可能登记成不同地区，所以 IP 查询网站显示“日本”，某个 AI 服务仍可能判成别处。

除了地区，部分服务还会看 IP 的类型和使用历史：数据中心（机房）IP、很多人共用的 IP，更容易遇到额外验证或限制。具体规则各服务没有公开，本站也没有测试过。节点地区的基础知识见[机场节点地区怎么选](/speedtest/node-regions-explained/)。

| 节点名 | 节点数 | OpenAI 标签 |
| --- | --- | --- |
| 香港 | 20 | 解锁(TW) |
| 台湾 | 10 | 解锁(TW) |
| 日本 | 10 | 解锁(JP) |
| 新加坡 | 10 | 解锁(SG) |
| 美国 | 10 | 解锁(US) |

关键在第一行：20 个名为“香港”的节点，OpenAI 判定的地区是 TW（台湾）。检测当时显示解锁，对应的地区是 TW，而不是“香港”这个名字。同一份检测里，这组香港节点的 YouTube、Netflix 都判为 HK，台湾节点的 Netflix 则被判为 ES（西班牙）：同一个出口，在不同服务眼里可能是不同地区。

局限：单次检测，截图自注“本测试为试验性结果，仅供参考”；检测项里只有 OpenAI，没有 Claude 与 Gemini；标签只说明连通性检测通过，不代表账号能长期正常使用；机场更换出口 IP 后结果可能变化。全部数据见[灵动云 60 个节点解锁检测记录](/speedtest/lingdongyun-2026-11-01-node-unlock-check/)。

### 2026-11-10 站长实测：日本5 节点

上午 10:54 在日本5 节点用 IPCheck.ing 测连通性：ChatGPT（23 ms）、Claude（26 ms）、Gemini（41 ms）、Perplexity（20 ms）都显示可用，报告注明 ChatGPT 另经实际打开，确认可正常使用。报告记录的出口位置是日本千叶县船桥市，出口网络为 Dodo K.K.（AS45691）。

局限：单次测试，只代表当天上午；本地运营商与城市未标注；Claude 与 Gemini 只有连通性结果，没有登录对话的记录。详见[灵动云日本5 节点实测报告](/speedtest/lingdongyun-2026-11-10-japan-node-report/)。

## 怎么选节点：从判定结果倒推

1. 先查你要用的服务的官方名单。按 2026-11-16 查阅的结果，台湾、日本、新加坡、韩国、美国在三家名单里都有。
2. 在名单内地区的节点里挑一个，直接打开服务，登录并发一条消息。
3. 能用就固定这个节点；不能用，先换同地区的其他节点，再换地区，不要凭一个节点就认定整个地区不行。
4. 名为“香港”的节点：按 OpenAI（API 页面）与 Anthropic 的名单，只有出口被判到名单内的地区时才可能可用（例如上面检测中的 TW）。这种判定会随出口 IP 变化，不宜长期依赖。

延迟不是重点。文字对话的数据量小，几十毫秒的差别不太能感觉到；更影响体验的是连接中途断开，回答生成到一半失败。

## 自己怎么查出口

| 方法 | 能看到什么 | 局限 |
| --- | --- | --- |
| 直接打开服务并登录 | 服务是否允许你使用、有没有地区提示 | 只代表当下这个节点 |
| IP 查询网站 | 出口 IP 的国家、城市、运营商与 ASN | 只是该网站所用地址库的判断，可能与 AI 服务不同 |
| 连通性检测（IPCheck.ing、MiaoKo 等） | 服务能否连通、工具判定的地区标签 | “可用”不等于全部功能可用 |
| 客户端的延迟测试 | 节点能否连上、延迟高低 | 不涉及服务对出口的判定 |

几种方法结论不一致时，以服务本身的表现为准。同一个节点隔几天再测一次，判定也可能变化。

## 固定节点，别在会话中途换地区

- 找到可用的节点就固定使用。用官方客户端时手动选定一个节点即可；用 Clash 系客户端时，把 AI 服务放进手动选择的代理组，不要用“自动选择”这类按延迟自动切换节点的组。
- 规则（分流）模式下，确认 ChatGPT、Claude、Gemini 的相关域名走同一个代理组，避免一部分请求直连、一部分走别的地区。在“连接”页面查看匹配规则的方法见[Clash Verge Rev 使用教程](/guides/clash-verge-rev-guide/)。
- 同一账号在手机和电脑上同时使用时，两边尽量连同一地区的节点。
- 各服务的风控规则不公开。短时间内出口地区频繁变化，可能被当作异常登录而要求重新验证；这是常见经验，本站没有测试过各服务的具体表现。

<Callout type="warning" title="先读服务条款">
OpenAI 的 API 支持国家和地区页面写明，在名单以外访问可能导致账号被封禁或暂停；Anthropic 的页面把人身处于不受支持地区时的使用列为不受支持。换节点改变的只是出口 IP，不改变这些条款。是否使用、怎么使用，请先阅读各服务的条款，自行评估风险。
</Callout>
