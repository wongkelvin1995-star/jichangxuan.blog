“已经开了代理，为什么游戏还是连不上海外服务器？”“为什么浏览器能用，终端里 git 还是超时？”这两个问题的答案都是同一个：你开的是系统代理，而那个应用不读系统代理。理解系统代理与 TUN 的区别，这类问题就不再神秘。

## 系统代理：告诉应用“代理在这里”

操作系统有一个全局的代理设置（Windows 在“设置 → 网络和 Internet → 代理”，macOS 在网络偏好的“代理”标签）。客户端开启“系统代理”时，做的事情只是把这个设置指向自己监听的本地端口（例如 127.0.0.1:7897）。

之后发生什么，取决于每个应用自己：

- **遵守系统代理的应用**：浏览器（Chrome、Edge、Firefox 默认跟随系统）、大多数聊天与办公软件、Steam 商店页面、Electron 应用等。它们会把 HTTP / HTTPS 请求发到本地代理端口。
- **不遵守的应用**：大量游戏客户端、很多命令行工具（curl、git、pip、npm 需要单独配置环境变量）、部分 UWP 应用、一些使用自有网络栈的软件。它们的流量直接走物理网卡，和没开代理一样。

系统代理的优点是轻：不需要管理员权限，不装驱动，关掉即恢复。缺点是覆盖不全，且只处理 TCP 上的 HTTP / SOCKS 流量，UDP 基本不管。

## TUN 模式：把网卡换成自己的

TUN 模式下，客户端创建一张虚拟网卡（Windows 上通常是 wintun 驱动，macOS 是 utun），并把系统默认路由指向它。此时所有应用的 IP 流量都会先进入这张网卡，由客户端按规则决定直连还是走哪个节点，再从物理网卡发出去。

因为接管发生在网络层，应用根本不知道代理的存在，所以：

- 所有应用都生效，包括游戏、命令行、不读代理设置的软件。
- TCP 和 UDP 都能处理（取决于节点协议是否支持 UDP 转发）。
- 需要更高的权限：Windows 上要安装系统服务或以管理员运行，macOS 要授权系统扩展或输入密码。
- DNS 由客户端接管，通常以 fake-ip 方式工作：先返回一个假 IP，等应用真正连接时再按域名匹配规则。这就是为什么开 TUN 后在终端里 ping 域名会看到 198.18.x.x 这类地址，属于正常现象。

手机上没有“系统代理 / TUN”的选项，因为 Android 的 VpnService 和 iOS 的 Network Extension 本来就是 TUN 的形式。手机上的安装与设置见[Android 客户端教程](/guides/android-client-setup/)和[iOS 客户端教程](/guides/ios-client-setup/)。

## 对比表

| 维度 | 系统代理 | TUN 模式 |
| --- | --- | --- |
| 覆盖范围 | 只有遵守系统代理的应用 | 全部应用 |
| 协议 | 主要是 TCP 上的 HTTP / HTTPS / SOCKS | TCP 与 UDP |
| 权限 | 普通用户即可 | 管理员 / 系统服务 / 系统扩展 |
| DNS | 应用自己解析或交给代理 | 客户端接管（fake-ip 或 redir-host） |
| 关闭后的残留 | 可能残留代理设置导致断网 | 虚拟网卡移除即恢复 |
| 常见冲突 | 浏览器扩展、其他代理软件 | 其他 VPN 软件、虚拟机网络、安全软件 |

## 按场景选择

- **只用浏览器看网页、用网页版 AI 工具**：系统代理。轻量、省事。
- **玩海外游戏、用桌面版游戏平台**：TUN。游戏基本不读系统代理，且很多用 UDP。
- **开发者用终端、Docker、包管理器**：TUN 最省心；不想开 TUN 的话，给终端设置 http_proxy / https_proxy 环境变量指向本地端口。
- **全家设备共用**：在一台电脑上开 TUN 只接管这台电脑的流量，不会让其他设备走代理。要带上其他设备，可以每台单独装客户端、用电脑的局域网共享，或者上路由器方案，三种做法的条件见[一家人多设备共用机场](/guides/multi-device-setup/)。
- **排查问题**：先只开系统代理测浏览器，再单独开 TUN 测其他应用，一次只改一个变量。连上了却打不开网页的完整排查顺序，见[DNS 与连接故障排查](/guides/dns-and-connection-troubleshooting/)。

## 在 Clash Verge Rev 里开启 TUN

下面以 Clash Verge Rev 为例，软件的其他设置见[Clash Verge Rev 使用教程](/guides/clash-verge-rev-guide/)。用它的前提是机场提供订阅链接，各家政策见[哪些机场支持 Clash Meta（Mihomo）订阅](/guides/clash-meta-compatible-airports/)；用品牌官方客户端的，有没有 TUN 开关以官方客户端的实际版本为准。

1. “设置”页面找到“服务模式”，安装系统服务（需要管理员授权）。
2. 打开“TUN 模式”开关。
3. 观察托盘图标或“连接”页面，确认流量开始经过客户端。
4. 若无法上网，先关闭 TUN 看系统代理是否正常，以区分 TUN 问题和节点问题。
