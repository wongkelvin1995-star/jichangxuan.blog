Clash Verge Rev 是目前 Windows、macOS、Linux 上最常被推荐的图形客户端：开源、界面清楚、内核是持续维护的 Mihomo，机场提供的 Clash 订阅基本都能直接用。这篇教程按“先连上，再调细节”的顺序写。

## 它是什么

- **图形界面 + 内核**：你操作的是 Clash Verge Rev 这个界面，真正处理流量的是它内置的 Mihomo 内核（也叫 Clash Meta）。
- **协议支持**：Shadowsocks、VMess、VLESS、Trojan、Hysteria2、TUIC 等，覆盖当前主流机场。
- **配置来源**：机场的订阅链接（Clash 格式），或者你自己写的 YAML。
- **获取方式**：项目的 GitHub Releases 页面。不要从搜索结果里的第三方下载站下载。

能不能用它，取决于机场给不给 Clash 订阅。不少机场只提供官方客户端、不发订阅链接，也有的要向客服申请，购买前先问清楚；各家的订阅政策见[哪些机场支持 Clash Meta（Mihomo）订阅](/guides/clash-meta-compatible-airports/)。

## 安装

下载对应平台的安装包。Windows 选 x64 的安装版（setup），macOS 按芯片选 aarch64（Apple 芯片）或 x64（Intel）。安装时 Windows 可能弹 SmartScreen 提示，确认来源后“仍要运行”。

安装完成第一次打开时，软件会询问是否安装系统服务。这个服务是 TUN 模式需要的；只用系统代理的话可以先跳过，之后随时能在设置里安装。

Windows 上官方客户端与订阅链接两条路线的对比，见[Windows 客户端教程](/guides/windows-client-setup/)。手机上没有 Clash Verge Rev：Android 可以用同为 Mihomo 内核的 Clash Meta for Android，见[Android 客户端教程](/guides/android-client-setup/)；iPhone 见[iOS 客户端教程](/guides/ios-client-setup/)。

## 导入订阅

1. 进入“订阅”页面。
2. 把机场给的订阅链接粘贴进顶部输入框，点“导入”。
3. 出现配置卡片后点击它，使其处于选中状态。
4. 卡片右键（或菜单）里有“更新”，建议设置“自动更新间隔”，例如 1440 分钟。

**导入失败**时按这个顺序排查：链接是否完整（有时复制会漏掉末尾字符）；订阅地址是否需要先连代理才能访问（先用其他方式连一次，或联系机场客服）；订阅是否已过期。

以[灵动云](/lingdongyun/)为例，资料显示订阅链接需要向客服询问，符合条件的套餐才会提供；拿到链接后导入方式和其他机场一致，申请流程见[灵动云客户端使用教程](/lingdongyun/lingdongyun-client-guide/)。

## 三种模式怎么选

“代理”页面顶部可以切换模式：

- **规则（Rule）**：按规则分流，国内直连、海外走代理。日常使用一直保持这个模式。
- **全局（Global）**：所有流量走选中的节点。只在排查“到底是规则没命中还是节点不通”时临时用。
- **直连（Direct）**：全部直连，相当于关闭代理但保留客户端运行。

## 选节点与延迟测试

代理页面会显示订阅里的“代理组”，比如“节点选择”“自动选择”“流媒体”等，每个组里是节点列表。

- 手动选：点组里的某个节点。
- 自动选：很多订阅带“自动选择（url-test）”组，它会定期测延迟并切换到延迟最低的节点。
- 延迟测试：点组右上角的闪电图标，对组内所有节点发一次 HTTP 请求。**这个数字是响应时间，不是下载速度**；超时的节点一定不可用，但延迟低的节点不一定快。

## 系统代理与 TUN

“设置”页面有两个开关：

- **系统代理**：把 Windows / macOS 的代理设置指向客户端，浏览器等遵守系统代理的应用生效。
- **TUN 模式**：创建虚拟网卡接管全部流量，所有应用生效；需要已安装系统服务。

两者的差别和取舍见[TUN 模式与系统代理有什么区别](/guides/tun-vs-system-proxy/)。日常用浏览器为主开系统代理即可；需要游戏、命令行工具走代理时开 TUN。不要同时依赖两个代理软件。

## 常用设置

- **开机自启 / 静默启动**：设置里打开，开机后自动在托盘运行。
- **端口**：Clash Verge Rev 默认混合端口为 7897（旧版 Clash 常用 7890）。需要给其他软件手动填代理时用这个端口。
- **局域网共享**：打开“允许局域网连接”后，同一网络里的其他设备可以把电脑 IP 加端口作为代理。电视、游戏机这类装不了客户端的设备怎么借用、有什么限制，见[一家人多设备共用机场](/guides/multi-device-setup/)。
- **DNS**：默认由内核处理，一般不用动。遇到解析问题时可以尝试切换“增强模式”（fake-ip 与 redir-host），完整的排查顺序见[DNS 与连接故障排查](/guides/dns-and-connection-troubleshooting/)。
- **Merge / 脚本**：高级用户可以在订阅之上叠加自己的规则，订阅更新也不会丢。
