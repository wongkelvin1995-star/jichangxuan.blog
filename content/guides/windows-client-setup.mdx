Windows 是机场用户最多的平台，也是教程最混乱的平台：有人让你装 Clash，有人让你下官方客户端，还有人甩给你一个 v2rayN 的压缩包。这篇教程按两条路线讲清楚，你只需要按自己拿到的东西选一条。

## 先弄清楚你拿到的是什么

购买套餐后，不同机场给你的东西不一样，这决定了你走哪条路线：

| 你拿到的 | 对应路线 | 典型品牌做法 |
| --- | --- | --- |
| 一个账号，官网提供“客户端下载” | 路线 A：官方客户端 | 登录即连，不需要导入任何东西 |
| 一串以 https 开头的“订阅链接” | 路线 B：第三方客户端 | 需要自己选客户端并导入 |
| 两者都有 | 先用 A，熟悉后再试 B | 进阶用户可按需切换 |

以[灵动云](/lingdongyun/)为例，资料显示它以官方客户端为主要入口，账号登录即可连接；订阅链接需要向客服询问，符合条件的套餐才会提供。所以第一次使用它的人直接走路线 A 即可，注册、登录与申请订阅的步骤见[灵动云客户端使用教程](/lingdongyun/lingdongyun-client-guide/)。

## 路线 A：官方客户端（账号登录即连）

官方客户端的界面各家不同，但流程几乎一致。

1. **从官网用户中心下载安装包**。只认官网，不认网盘、群文件和“加速版”。下载前看一眼地址栏的域名是否就是你注册时的域名。
2. **运行安装包**。Windows 可能弹出 SmartScreen 的蓝色提示，这是对未签名程序的常规警告；确认来源无误后点击“更多信息 → 仍要运行”。部分杀毒软件会把代理软件误报为风险程序，如果你确定来源可靠，可以把安装目录加入信任区。
3. **登录账号**。用注册官网时的账号密码登录；部分客户端会在登录后自动拉取节点列表。
4. **选择节点并连接**。第一次使用建议选香港、台湾或日本这类延迟低的地区。客户端通常有“测试延迟”按钮，数值越低越好，但延迟低不等于速度快。
5. **验证是否生效**。打开一个平时打不开的海外网站，或者访问 IPCheck.ing 一类的检测页，看显示的出口 IP 地区是否变成了你选的节点所在地。

官方客户端一般会自动处理系统代理或 TUN，你不需要手动设置。退出客户端时记得先断开连接，否则有些客户端会把系统代理留在开启状态，导致关掉软件后反而上不了网。

## 路线 B：订阅链接 + Clash Verge Rev

拿到订阅链接后，Windows 上最常见、也最省心的选择是 Clash Verge Rev（基于 Mihomo 内核，开源，支持当前主流协议）。完整设置见[Clash Verge Rev 使用教程](/guides/clash-verge-rev-guide/)，这里只走一遍最短路径。

前提是机场给订阅链接。不少机场只提供官方客户端，各家政策见[哪些机场支持 Clash Meta（Mihomo）订阅](/guides/clash-meta-compatible-airports/)。

### 第 1 步：安装

从项目的 GitHub Releases 页面下载 Windows 安装包（一般选 x64 版本），双击安装。安装过程同样可能遇到 SmartScreen 提示，处理方式同上。

### 第 2 步：导入订阅

打开软件，进入“订阅”（Profiles）页面，把订阅链接粘贴到顶部输入框，点击“导入”。导入成功后会出现一张配置卡片，点击它激活。

如果导入失败，常见原因有三个：订阅链接复制时带了多余字符；订阅服务器本身需要代理才能访问（先用别的方式连一次再导入，或联系机场客服）；订阅已过期或流量用完。

### 第 3 步：开启系统代理

进入“设置”页面，打开“系统代理”开关。这一步让 Windows 把浏览器等应用的流量交给客户端处理。

### 第 4 步：选节点

回到“代理”页面，在代理组里选一个节点。代理模式保持“规则”（Rule）：国内网站直连，海外网站走代理，这是日常使用最合理的方式。全局模式只在排查问题时临时使用。

### 验证

和路线 A 一样，打开海外网站或检测页确认出口 IP。此外，Clash Verge Rev 的“连接”页面能看到每条连接走了哪个节点，排查问题很有用。显示已连接却打不开网页，按[DNS 与连接故障排查](/guides/dns-and-connection-troubleshooting/)的顺序处理。

## 系统代理还是 TUN

系统代理只对“遵守系统代理设置”的应用有效：浏览器、大多数聊天软件、Steam 商店页面等。很多游戏、命令行工具和一部分桌面应用不读系统代理，它们的流量会直接走你的宽带。

如果你需要让所有应用都走代理，就要用 TUN 模式：客户端创建一张虚拟网卡接管全部流量。Clash Verge Rev 开启 TUN 需要安装系统服务（会提示获取管理员权限）。两种模式的差别和取舍，见[TUN 模式与系统代理有什么区别](/guides/tun-vs-system-proxy/)。

## 手机和家里的其他设备

手机上的步骤不同：见[Android 客户端教程](/guides/android-client-setup/)和[iOS 客户端教程](/guides/ios-client-setup/)。

在电脑上开 TUN 只接管这台电脑自己的流量，不会顺带让家里其他设备走代理。全家多台设备一起用，先看套餐的设备数和流量是否共用，电视、游戏机怎么接，见[一家人多设备共用机场](/guides/multi-device-setup/)。

## 安全提醒

- 只从官网或项目官方仓库下载客户端；网上出售的“订阅链接”和网盘里的“客户端安装包”都不是官方渠道。
- 订阅链接等同于账号凭证，不要发到群里或贴图分享。
- 客户端要求关闭杀毒软件、修改 hosts 以外的系统文件时，停下来先问客服。
