Android 上使用机场的门槛比 Windows 低：没有系统代理和 TUN 的区分（原因见[TUN 模式与系统代理有什么区别](/guides/tun-vs-system-proxy/)），所有客户端都通过系统的 VPN 接口工作，装好、授权、连接就行。麻烦的地方在后面：后台被杀、DNS 设置冲突、各品牌手机的省电策略。这篇按顺序把这些都讲清楚。

## 两条路线

和[Windows 客户端教程](/guides/windows-client-setup/)里一样，先看你拿到的是什么：

- **账号 + 官方客户端**：从官网下载 APK，登录即连。[灵动云](/lingdongyun/)的资料显示它以官方客户端为主要入口，走这条路线，流程见[灵动云客户端使用教程](/lingdongyun/lingdongyun-client-guide/)。
- **订阅链接**：用 Clash Meta for Android（简称 CMFA，基于 Mihomo 内核的开源客户端）或其他支持你机场协议的客户端导入。不是每家机场都发订阅链接，各家政策见[哪些机场支持 Clash Meta（Mihomo）订阅](/guides/clash-meta-compatible-airports/)。

iPhone、iPad 的步骤见[iOS 客户端教程](/guides/ios-client-setup/)。家里多台设备一起用，先看套餐的设备数与流量是否共用，手机热点为什么带不动其他设备，见[一家人多设备共用机场](/guides/multi-device-setup/)。

## 路线 A：官方客户端

1. **下载 APK**。在手机浏览器里打开官网用户中心，找到 Android 客户端下载。只从官网下载，不要用群里转发的安装包。
2. **允许安装**。首次安装浏览器下载的 APK 时，系统会要求允许“安装未知应用”，为浏览器打开这个权限即可，装完可以再关掉。
3. **登录并连接**。打开客户端登录账号，选一个节点，点击连接。
4. **允许 VPN 连接请求**。系统会弹出“此应用想设置 VPN 连接”，点击“确定”。状态栏出现钥匙图标表示虚拟网卡已建立。
5. **验证**。打开海外网站或访问 IPCheck.ing 一类的检测页，确认出口 IP 变成了节点所在地。

## 路线 B：Clash Meta for Android

### 安装

从项目的官方 GitHub Releases 下载对应架构的 APK（大多数手机选 arm64-v8a）。安装方式同上。

### 导入订阅

1. 打开应用，进入“配置”，点击右下角新建。
2. 选择“URL”，把订阅链接粘贴进去，可以起个名字，设置“自动更新”间隔（例如 1440 分钟即一天一次）。
3. 保存后点击该配置将其选中。

### 连接

回到主界面点击“启动”，允许 VPN 连接请求。进入“代理”页面，在代理组里选择节点；模式保持“规则”。CMFA 和电脑上的 Clash Verge Rev 用的是同一个内核，代理组、规则与全局模式的含义见[Clash Verge Rev 使用教程](/guides/clash-verge-rev-guide/)。

### 常用设置

- **应用分流**：在设置里可以选择“允许”或“绕过”某些应用。把银行、支付、国内视频类应用加入绕过列表，既快又省流量。
- **自动更新订阅**：建议开启，否则节点变动后旧配置会连不上。
- **延迟测试**：代理页面可以对整个代理组测延迟，数值仅表示连通性与响应快慢，不是下载速度。

## 后台被杀：Android 上最常见的问题

Android 各品牌的省电策略会在你锁屏一段时间后把客户端杀掉，表现为“连一会儿就断”“切回应用发现已断开”。处理方法：

1. 系统设置 → 应用 → 找到客户端 → 电池，选择“不受限制”或“不优化”。
2. 允许自启动与后台运行（不同品牌名称不同，一般在“应用管理”或“权限管理”里）。
3. 在最近任务卡片上锁定该应用。
4. 关闭系统的“智能省电”“超级省电”模式，这些模式会无差别限制后台。

## DNS 冲突：“私人 DNS”

Android 9 以上有“私人 DNS”（Private DNS）设置。如果你之前设置过某个 DoT 服务器，它可能与客户端的 DNS 处理冲突，表现为连上后部分网站打不开。到“设置 → 网络和互联网 → 私人 DNS”改为“自动”或“关闭”，再试一次。更多 DNS 问题见[DNS 与连接故障排查](/guides/dns-and-connection-troubleshooting/)。

## 安全提醒

- 装前看权限：代理客户端需要 VPN 权限是正常的，但不应该索要通讯录、短信、位置。
- 订阅链接等于账号凭证，不要截图分享。
- 不要为了“免 VPN 弹窗”去安装来路不明的修改版客户端。
