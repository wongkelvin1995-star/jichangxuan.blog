iOS 上用机场的障碍不在技术，而在 App Store：中国区商店没有代理类应用，所以第一步永远是解决“从哪里下载”。解决之后，导入订阅、连接、验证都比电脑上简单。

## 第一步：解决 App Store 区域

代理类 App 只在非中国区的 App Store 上架。你需要一个美区、港区或其他地区的 Apple ID。

- **只在 App Store 里登录这个账号**。打开 App Store，点右上角头像，退出当前账号，登录非中国区账号。iCloud、iMessage 保持你自己的主账号不动，这样不会影响照片、备份和通讯录。
- **不要使用网上共享的 Apple ID**。共享账号随时可能被改密码，还可能被用来远程锁定设备。
- 注册非中国区 Apple ID 的方法不在本文范围内，网上教程很多，核心是地区选择与付款方式填“无”。

## 第二步：选择客户端

### 品牌官方客户端

部分机场提供自己的 iOS 客户端（通过 App Store 或 TestFlight 分发）。如果你的机场提供，优先用它：登录即连，不用管订阅。[灵动云](/lingdongyun/)的资料提到客服可以协助处理 iOS 客户端相关问题，具体安装方式以客服答复为准，本站没有该客户端的安装截图，不在此猜测；它的注册与登录流程见[灵动云客户端使用教程](/lingdongyun/lingdongyun-client-guide/)。

### 第三方客户端

前提是机场给订阅链接；只提供官方客户端的机场用不了这些 App，各家政策见[哪些机场支持 Clash Meta（Mihomo）订阅](/guides/clash-meta-compatible-airports/)。拿到订阅链接的用户常用这几个付费 App（价格以 App Store 为准，会随汇率和地区变化）：

| App | 特点 |
| --- | --- |
| Shadowrocket | 最常见，支持主流协议，一次买断 |
| Stash | 基于 Clash 规则体系，熟悉 Clash 的用户上手快 |
| Loon | 规则与脚本能力强，偏进阶 |
| Quantumult X | 功能多，配置复杂，偏进阶 |

新手选 Shadowrocket 即可；下面以它为例。

## 第三步：用 Shadowrocket 导入订阅

1. 打开 Shadowrocket，点右上角“+”。
2. “类型”选择“Subscribe”，在“URL”里粘贴订阅链接，备注随意，点“完成”。
3. 回到首页，下拉刷新或在订阅上点“更新”，节点列表会出现。
4. 点选一个节点（建议先选香港、台湾、日本），打开顶部的连接开关。
5. 第一次连接时系统会请求“添加 VPN 配置”，输入锁屏密码或用 Face ID 允许。
6. “全局路由”保持“配置”（按规则分流），不要长期用“代理”（全局）。

验证方法：打开海外网站，或访问 IPCheck.ing 看出口 IP 地区。连上后部分网站打不开，按[DNS 与连接故障排查](/guides/dns-and-connection-troubleshooting/)的顺序处理。

## 第四步：理解 iOS 的 VPN 配置

iOS 把所有代理客户端都当作 VPN 来管理。打开“设置 → VPN”（或“设置 → 通用 → VPN 与设备管理”），能看到客户端创建的配置和当前状态。几件事值得知道：

- 开关可以在这里切换，不必打开 App。
- 同一时间只能有一个 VPN 配置处于连接状态。
- 客户端的“按需连接”（On Demand）打开后，系统会在网络变化时自动重连。

## 电脑和家里的其他设备

电脑和安卓手机的步骤见[Windows 客户端教程](/guides/windows-client-setup/)、[Android 客户端教程](/guides/android-client-setup/)。iPhone、iPad 和家里其他设备共用一个套餐时，先看套餐的设备数和流量是否共用，见[一家人多设备共用机场](/guides/multi-device-setup/)。

## 安全提醒

- 不要在 iCloud 里登录共享账号，只在 App Store 登录。
- 订阅链接不要分享；更换手机时重新导入即可。
- 系统弹出“添加 VPN 配置”是正常流程；但如果某个 App 要求安装“描述文件”或“证书”才能用，先确认它是官方渠道。
