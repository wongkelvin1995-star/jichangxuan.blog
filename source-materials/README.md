# source-materials：站主提供的原始资料（只读）

本目录保存站主提供的品牌资料原文与测试截图，是网站上所有套餐、节点、优惠码、客服政策与测速数值的唯一来源。

规则：

- 不修改原件；资料更新时新增文件并在文件名中注明日期。
- `data/brands.json`、`data/plans.json` 与 `content/` 中的数据只能来自这里的文件，并在页面上注明资料日期。
- 截图中的订阅标识、账号等敏感信息须先脱敏再放入。
- 证据图由 `npm run og`（scripts/generate-images.mjs）转为 ≤1600px 的 webp 放到 `public/images/evidence/`，页面引用转换后的文件。
- 资料缺口与冲突的逐品牌检查见 `docs/brand-materials-audit.md`。
